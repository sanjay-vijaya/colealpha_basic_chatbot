# 🤖 Basic Rule-Based Chatbot

A beginner-friendly **Rule-Based Chatbot built using Python**.  
This chatbot interacts with users through predefined responses and provides basic information about programming languages and Python concepts.

## 📌 Project Overview

The chatbot uses Python fundamentals such as:

- Conditional Statements
- Functions
- Loops
- User Input and Output
- String Handling
- Date and Time
- Rule-Based Responses

It can understand different predefined user inputs and provide appropriate responses.

## ✨ Features

- 👋 Greeting responses
- 🤖 Chatbot name and introduction
- 🕐 Display current time
- 📅 Display current date
- 💻 Information about programming languages
- 🐍 Python concept explanations
- 📚 Python data type explanations
- 🔢 Operator explanations
- 🔀 Conditional statement explanation
- 🧩 Function explanation
- 🇮🇳 English, Tamil and Tanglish responses
- 💬 Interactive conversation using a continuous loop
- ❌ Exit commands such as `bye`, `exit`, and `quit`

## 🛠️ Technologies Used

- **Python**
- **Python datetime module**

## 📚 Python Topics Covered

The chatbot provides information about:
